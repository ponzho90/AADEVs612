Conectar con GitHub (una sola vez)

Crea un token en GitHub: Settings → Developer settings → Fine-grained tokens. Elige tus repositorios y da permiso de lectura/escritura a Pull requests, Issues, Actions (lectura) y Contents (lectura). El token se guarda solo en este navegador y solo viaja a api.github.com.
